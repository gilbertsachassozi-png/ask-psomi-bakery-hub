# 🥖 Ask Psomi Keik Bakery - Order Hub & Management Platform

A data-driven, full-stack order management and automated pricing platform designed for **Ask Psomi Keik Bakery** located in **Lutaba, Uganda**. This software streamlines localized walk-in retail transactions, bulk supply estimations, and custom celebration cake orders.

## 🛠️ Tech Stack & Engineering Core
* **Backend Framework:** Python (Flask)
* **Frontend Logic Engine:** Vanilla JavaScript (ES6+)
* **Interface & Presentation:** HTML5, Custom CSS3 Grid Theme
* **Environment Architecture:** Jinja2 Templating Ecosystem

## 🚀 Key Software Architectures Implemented
1. **Dynamic Client-Side Telemetry:** Engineered a responsive JavaScript event listener that captures form input variables to dynamically calculate running transaction totals live on screen without page-refresh overhead.
2. **Multi-Item Parsing Processing:** Designed a Python backend dictionary matrix capable of concurrently processing high-volume retail quantities across multiple items simultaneously.
3. **Fulfillment Metadata Logging:** Implemented data logging pathways to capture essential pickup time criteria and mobile money network designations.
4. **Administrative Back-Office Pipeline:** Developed a secure administration dashboard (`/admin`) utilizing hardcoded credential encryption filters to track operational pipeline fulfillment histories.
5. **API / String Integration Routing:** Integrated an automatic URL parameter string-encoder that packages the processed invoice structure into a direct clickable WhatsApp notification linked straight to the production desk.
